STEP 01

复制一份代码到你自己名下

整个简报跑在你自己的 GitHub 仓库里，抓取和发信都用你自己的账号，没有中间服务器，别人碰不到你的数据。

Fork 仓库

打开 github.com/Gv1k/daily-brief， 点右上角 Fork，建议 fork 成 Private（私有）仓库——里面会存你的问卷画像，不建议公开。

点完 Fork 之后，页面会跳转，网址栏会变成你自己的用户名——这就说明成功了：

STEP 02

准备两把钥匙

都是免费/接近免费，5分钟内能搞定，跟着链接走就行。

① DeepSeek API Key（AI摘要用）

打开 platform.deepseek.com 注册 → 左侧 API keys → 创建一个 key 复制好 → 左侧充值页面充 1~5 元（每天两次简报的调用量很省，几块钱能用很久）。

② QQ邮箱授权码（发信用）

登录你的 QQ 邮箱网页版 → 设置 → 账户 → 找到"POP3/IMAP/SMTP服务" → 开启 SMTP 服务 → 按提示发短信验证 → 会得到一串16位的授权码，复制好（这不是你的QQ密码，是单独生成的）。

③ Supabase 项目（可选，用于早晚去重）

打开 supabase.com，免费注册并新建一个项目 → 左侧 SQL Editor，运行一次建表语句（在你 fork 的仓库 seen_records.py 文件顶部注释里）→ 左侧 Project Settings → API，复制 Project URL 和 anon public key。不填也能正常收到简报，只是早晚内容可能会重复。

④ 关于教务网这块

目前只内置了西南交通大学教务网的抓取。如果你是西南交大的同学，不用做任何设置，简报会自动帮你盯着教务网新通知。 如果你不是西南交大的同学，教务网这部分直接留空跳过就行——不影响科技资讯、GitHub Trending 等其它内容正常生成和发送， 你也可以自己改 fetch_jwc_news.py 适配你学校的教务网（代码不复杂，欢迎发 PR 一起完善）。

进到这个页面后，左侧会有个 Secrets and variables，点开选 Actions， 右上角有个绿色按钮：

New repository secret

点开后会出现两个框：Name（填Secret的名字，比如 DEEPSEEK_API_KEY， 要跟下面清单里完全一样，区分大小写）和 Secret（粘贴对应的值），填完点 Add secret。 下面清单里的每一行都要这样重复添加一次，一共要加这么多个。
